# YOLOv3 Project — Agent Guide

## Stack
- Python 3.10, uv package manager
- PyTorch 2.3.0 / torchvision 0.18.0 (CUDA 11.8 wheels via `https://download.pytorch.org/whl/cu118`)
- Lint: ruff (`ruff.toml`); Google-style docstrings required
- Logging: TensorBoard → `runs/<timestamp>/`

## Key Commands
```bash
uv run train.py          # train (batch=2, 120 epochs, SGD lr=0.01)
uv run detect.py         # webcam inference (default entrypoint)
ruff check .             # lint
```

## Architecture
- `nets/yolov3.py` — `YoloBody` (Darknet-53 backbone + FPN + 3 YOLO heads with RetinaNet prior bias init)
- `utils/decode.py` — `decode_preds` shared decoding logic for loss and postprocess
- `utils/dataloader.py` — `YOLODataset` / `CocoDataset` / `yolo_collate_fn`
- `utils/loss.py` — `YOLOLOSS` (GIoU + Focal Loss + global 9-anchor matching)
- `utils/nms.py` — `non_max_suppression`
- `utils/postprocess.py` — `secend_stage()` post-processes raw model output into pixel coordinates
- `detect.py` — Unified detection entrypoint (auto-detects webcam index vs image file path)
- `label_util/` — COCO/VOC annotation-to-text converters

## Dataset Format
Text file, one line per image:
```
/path/to/img.jpg x_min,y_min,x_max,y_max,class_id x_min,y_min,...
```
Generated by `label_util/coco_util.py` or `label_util/voc_util.py`.
Default training file: `coco_train.txt`; class list: `data/coco_names.yaml`.

## Weights & Checkpoints
- Pre-trained checkpoints are **not** committed (in `.gitignore`). Load a `.pth` from the project root, e.g. `1000_0.2988.pth`.
- During training, checkpoints are saved every 1000 steps to `weights/<step>_<loss>.pth` via a `.checkpoint.pth` temp file (see `train.py:100-104`).
- `evaluation.py` currently references an external `u_yolov5` package and is non-functional — do not rely on it.

## Gotchas
- `train.py` hard-codes `model = torch.load(r"53000_0.3136.pth", …)` — you must replace or comment this out to train from scratch.
- `detect.py` hard-codes `torch.load(r"1000_0.2988.pth", …)` — update to match your checkpoint.
- `coco_util.py` and `voc_util.py` contain Windows paths (`D:\Python\datasets\…`) — update before running.
- Image normalization mean/std (`0.4711, 0.4475, 0.4080` / `0.2378, 0.2329, 0.2361`) were computed on the training set and should not be changed.
- `evaluate.py` imports `u_yolov5.models.yolo.Model` — this is a stale reference; ignore it.

## Directories
- `weights/` — saved model checkpoints (gitignored)
- `runs/` — TensorBoard logs
- `img/` — example images (gitignored)
- `config/` — configuration files (gitignored)
- `data/` — YAML class lists and label index files
